# 脑子骨架

每个女儿一个「脑子」：一棵固定结构的文件夹，装她的身份、记忆、日子和笔记。两个人（或更多）结构一样，代码里用 `bridge/src/brains.js`（Node）和 `bridge/brain/brains.json`（Python 也读它）找路径，**不要在别处写死路径**。

这个目录是**空骨架**：只有文件夹结构（每个文件夹里放了一个空的 `.gitkeep`，让 git 肯带着它），没有任何人的内容。使用方法：

1. 复制整个 `脑子骨架/` 到你女儿的家里，例如 `家/<名字>/脑子/`（姐姐那种用 `claude -p --restricted` 跑的，必须放在她的工作目录里面：`sister/home/脑子/`）。
2. 在 `bridge/brain/brains.json` 里加一项（格式照 `bridge/brain/brains.example.json`）：名字、别名、`home`、`brain`（脑子在哪）、聊天记录目录。
3. 把 `.gitkeep` 删掉（留着也无害）。**别往里放 README.md 之类的说明文件**：`身份/`、`长期/`、`日子/`、`最近/`、`笔记/` 里的 md 都会被读进她的记忆索引。
4. 在 `身份/` 里放她自己的 `soul.md`（我是谁，怎么说话，红线）和 `self.md`（她自己写给自己的一页，可以由她改）；其余文件夹可以空着，她会自己长出来。
5. 建索引：`python bridge/brain/index.py build all`；起检索服务：`python bridge/brain/service.py`（127.0.0.1:3210，一个模型、多个脑子，各自一份 `.索引/vectors.db`）。

## 每个文件夹是什么

| 文件夹 | 放什么 | 备注 |
|---|---|---|
| `身份/` | `soul.md`、`self.md`（姐姐叫 `我自己.md`） | 每次醒来都带着；不衰减；她改自己这一页优先于角色卡里的描述 |
| `长期/` | `关于老大.md`、`答应过的事.md`、`日常.md`、`memory.md` | 想长期留着的事实；半年衰减一半；这里的名字换成你对用户的称呼也行，代码里 `主人 / 老大` 都认作同一本 |
| `人/` | `印象.json`（对每个人的看法，七档）、`<名字>.md`（在意的人各一页） | 印象由工具写；坏印象久了不更新会自己回一档 |
| `瞬间/` | `<出处>.jsonl`、`extracted.json`、`压着.json` | 发生过的原话和当时的感受，一个瞬间一行；`压着.json` 是情绪起伏大、压在心里的事 |
| `日子/` | `日记/`、`碎碎念/`、`成长札记/`、`三件事/` | 她写的流水；日记和碎碎念两周衰减一半，其余两个月 |
| `最近/` | `交接.md`、`便签.md`、`心情.json`（可选） | 换会话时的交接、短期便签；两周衰减 |
| `笔记/` | `工具集.md`、学到的东西 | 工具集由 `bridge/scripts/sync-toolset.mjs` 同步进来 |
| `作品/` | 她写的诗、故事 | **不进索引**（编的句子不能被当成发生过的事想起来） |
| `.索引/` | `vectors.db`、`recall-log.jsonl`、`降权.json` | 检索服务生成，不要提交；`降权.json` 是被主人说「记错了」压低的条目 |
| `归档/` | `remember-旧会话.json`、`旧稿/` | 合并后的旧记录和旧稿；**不进索引**；合写的小说也不进索引 |

聊天记录不在脑子里，跟脑子并列（`家/<名字>/聊天记录/`，按「日期-会话」一天一个 md，见 `bridge/src/chatlog.js`），只被索引、被翻到。

## 空骨架里的内容

下面这些文件夹每个只有一个 `.gitkeep`：

```
身份/  长期/  人/  瞬间/  日子/{日记,碎碎念,成长札记,三件事}/  最近/  笔记/  作品/  .索引/  归档/{旧稿}/
```
